# 強み言語化パートナー (200の問い #003)

無意識の才能を「稼げる言葉」に変換するAIプロンプト生成ツール。

## 特徴 (δ方式)

- API呼び出しゼロ・コストゼロ・永久動作
- ChatGPT / Claude / Gemini のどれでも使える
- 5つの問いに答えるだけで、最適化された分析プロンプトを自動生成
- 履歴保存、他者視点プロンプト、深掘りプロンプト機能付き

## 使い方

1. 5つの問いに答える
2. 生成されたプロンプトをコピー
3. お使いのAI(ChatGPT等)に貼り付け
4. 結果を貼り戻して履歴に保存

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## デプロイ

Vercelに接続するだけで自動デプロイされます。
